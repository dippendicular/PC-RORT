# PC-RORT modules

- `matrix.py`: conditional second-moment `Q=B+V` and local-relative contrast.
- `robust.py`: PSD-constrained general-J robust optimization with CVXPY.
- `uncertainty.py`: experimental simultaneous bootstrap uncertainty proposals.
- `evidence.py`: pair eligibility and evidence contracts.
- `deliberation.py`: signed relation-aware multimodal deliberation.
- `selective.py`: temperature/conformal prediction policy.
- `cli.py`: quick demo and web-app startup.

For usage, see the repository [README](../README.md) and
[experiment guide](../docs/EXPERIMENTS.md).
